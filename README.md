# otp-input

Accessible one-time code input for React (shadcn/ui style):
one box per digit, auto-advance, backspace and arrow-key navigation,
paste support, controlled or uncontrolled, numeric or alphanumeric.
No dependencies beyond React.

- Component: [`registry/components/otp-input/otp-input.tsx`](registry/components/otp-input/otp-input.tsx)
- Docs and props: [`registry/README.md`](registry/README.md)
- Demo: [`registry/demos/default.tsx`](registry/demos/default.tsx)

Install (after it is listed on UpFork):

```bash
npx shadcn@latest add @upfork/otp-input
```
